ICS Calendar Builder and Validator

Paste an .ics calendar file and get RFC 5545 findings grouped into MUST violations, SHOULD-level findings and interoperability notes, or build an event file folded correctly at 75 octets. One HTML file, nothing leaves your browser.

Input

Two input paths, and they are not equivalent. The uploaded-file path gives this page the raw octets, so every byte-level check is exact. The paste path does not.

Read locally with FileReader. The file is never uploaded anywhere.

Your browser decodes pasted text before this page sees it, so three checks are weaker on this path. The page says so on screen when you use it.

The three tiers

  • MUST A normative requirement of RFC 5545 is not met. The object does not conform.
  • SHOULD The RFC recommends against this, using the word SHOULD or SHOULD NOT. It is a recommendation, not a requirement.
  • NOTE An interoperability observation. The RFC does not forbid it.

A file that fails only SHOULD-level checks is still a conforming iCalendar object. The three counts are reported separately and are never added together into one error number.

NOTE, INPUT PATH

Pasted text was decoded by your browser before this page saw it. The line-ending, the split-codepoint and the charset checks are exact only on the uploaded-file path.
